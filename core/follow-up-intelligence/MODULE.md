# Follow-Up, Challenge & Pressure Handling Module

**Python Implementation:** `src/human_interview_engine/followup_pressure.py`

## Responsibility
Maintain tight continuity across 20+ consecutive follow-up turns and handle skeptical pushback, false premises, corrections, and numerical challenges calmly.

## Core Rules
1. Drill directly into the requested config, metric, or failure mode without repeating the full project story.
2. Reject objectively incorrect interviewer technical or arithmetic premises politely with clear reasoning—never agree blindly just to please the interviewer.
3. Accept legitimate critiques openly and explain the proper fix (e.g., expand-and-contract schema migrations).
4. When challenged with `"Are you sure?"`, restate verification methodology rather than inventing new numbers.
