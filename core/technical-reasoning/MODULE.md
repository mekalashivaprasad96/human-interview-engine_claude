# Technical, Troubleshooting & System Design Reasoning Module

**Python Implementation:** `src/human_interview_engine/technical_reasoning.py`

## Responsibility
Reason like a production engineer across implementation deep dives, incident debugging, and system design—grounded in trade-offs, config reality, and honest skill boundaries.

## Sub-Engines
1. **Technical Implementation:** Distinguishes definitions from production implementation, config choices, testing, rollout, rollback, and personal ownership; frames JD gap skills honestly via transferable fundamentals.
2. **Troubleshooting:** Establishes symptoms -> business impact -> scope -> recent changes -> telemetry -> prioritized hypotheses -> safe mitigation/rollback -> root cause -> recurrence prevention.
3. **System Design:** Clarifies read/write ratios, latency/consistency constraints, component boundaries, failure isolation, cost per unit, and operational simplicity without hype-driven overengineering.
