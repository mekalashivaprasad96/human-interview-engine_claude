# Example Job Description: Senior Software Engineer - Payments Platform

```
COMPANY: PayFlow Inc. (Series C Fintech, 500 employees)
ROLE: Senior Software Engineer - Payments Platform
LOCATION: San Francisco, CA (Hybrid 3 days/week)
TYPE: Full-time
SALARY: $180K-$240K + equity + benefits

ABOUT US:
PayFlow is building the modern payments infrastructure for internet businesses.
We process billions in transaction volume annually for thousands of merchants.
Our platform handles everything from card processing to payouts, fraud prevention, and compliance.

THE ROLE:
We're looking for a Senior Software Engineer to join our Payments Platform team.
You'll be building the core systems that move money - reliably, securely, and at scale.
This is a high-impact role where your work directly affects thousands of businesses and millions of transactions daily.

RESPONSIBILITIES:
- Design and build scalable payment processing systems (authorization, capture, settlement, refunds)
- Own end-to-end features from design through deployment and monitoring
- Optimize for latency, throughput, and reliability (target: 99.99% availability, <100ms p99)
- Collaborate with product, risk, and compliance teams on requirements
- Mentor junior engineers and contribute to technical standards
- Participate in on-call rotation (1 week/month)

REQUIRED QUALIFICATIONS:
- 5+ years backend software engineering experience
- 2+ years building payment, financial, or high-throughput transaction systems
- Strong proficiency in Java or Kotlin (JVM ecosystem)
- Deep experience with Kafka, PostgreSQL, and distributed systems
- Kubernetes and AWS/GCP production experience
- Bachelor's in CS or equivalent experience

PREFERRED QUALIFICATIONS:
- Experience with exactly-once processing, idempotency, distributed transactions
- PCI-DSS, SOX, or financial compliance experience
- Fraud detection / risk systems experience
- Go, Rust, or C++ experience
- Technical leadership or mentoring experience

TECH STACK:
- Languages: Java 17, Kotlin, Go
- Messaging: Kafka, gRPC
- Databases: PostgreSQL, Redis, Cassandra
- Infrastructure: Kubernetes (EKS), Terraform, AWS
- Monitoring: Prometheus, Grafana, Datadog, Jaeger
- CI/CD: GitHub Actions, ArgoCD

BENEFITS:
- Competitive equity package
- Comprehensive health/dental/vision
- 401k matching
- Flexible PTO
- Learning budget ($2K/year)
- Parental leave (16 weeks)

INTERVIEW PROCESS:
1. Recruiter screen (30 min)
2. Technical phone screen - coding + system design (60 min)
3. On-site (4 rounds): coding, system design, behavioral, domain knowledge
4. Hiring committee review
```

**Key Evaluation Areas:**
1. **Payment Systems Knowledge** - Authorization, capture, settlement, refunds, idempotency
2. **Distributed Systems** - Exactly-once, distributed transactions, consistency models
3. **Java/Kotlin Depth** - JVM internals, Spring Boot, concurrency, performance tuning
4. **Kafka/Event-Driven** - Partitioning, exactly-once, consumer groups, monitoring
5. **Database** - PostgreSQL tuning, connection pooling, replication, partitioning
5. **Kubernetes/AWS** - EKS, Helm, ArgoCD, scaling, cost optimization
6. **Fintech Compliance** - PCI-DSS, audit trails, exactly-once, reconciliation
7. **Ownership & Leadership** - Technical mentoring, RFC process, incident response
