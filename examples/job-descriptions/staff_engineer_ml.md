# Example Job Description: Staff Engineer - ML Infrastructure

```
COMPANY: RecommenderAI (Late-stage startup, 800 employees)
ROLE: Staff Engineer - ML Infrastructure
LOCATION: New York, NY (Hybrid)
TYPE: Full-time
SALARY: $250K-$350K + significant equity

ABOUT US:
RecommenderAI powers personalized experiences for the world's largest apps.
Our recommendation platform serves 500M+ users across social, e-commerce, and streaming.
We're building the infrastructure that makes real-time ML accessible at massive scale.

THE ROLE:
As a Staff Engineer on the ML Infrastructure team, you'll architect the systems that power
real-time feature computation, model serving, and experimentation for hundreds of models.
You'll define technical strategy, mentor senior engineers, and drive cross-org initiatives.

RESPONSIBILITIES:
- Architect real-time feature store and model serving platform (10M+ QPS)
- Define technical roadmap for ML infrastructure (12-18 month horizon)
- Lead cross-functional initiatives with ML, product, and data teams
- Mentor 5+ senior engineers across multiple teams
- Drive technical standards: code review, design docs, incident response
- Represent engineering in executive technical reviews

REQUIRED QUALIFICATIONS:
- 8+ years distributed systems engineering
- 3+ years ML infrastructure (feature stores, model serving, training platforms)
- Proven technical leadership (Staff/Principal equivalent)
- Expert in C++ and/or Python for high-performance systems
- Deep knowledge of distributed systems: consistency, partitioning, replication
- Experience with TensorFlow, PyTorch, or JAX at scale

PREFERRED QUALIFICATIONS:
- Feature store implementation (Feast, Tecton, or custom)
- Real-time ML: streaming features, online learning, embedding serving
- Kubernetes operator development
- Published research (VLDB, SIGMOD, OSDI, KDD, RecSys)
- Multi-region / multi-cloud deployment experience

TECH STACK:
- Languages: C++, Python, Go, Rust
- ML: TensorFlow, PyTorch, XGBoost, ONNX, TensorRT
- Streaming: Flink, Kafka, Custom stream processing
- Storage: Cassandra, Redis, RocksDB, S3, Custom columnar
- Orchestration: Kubernetes, Airflow, Custom schedulers
- MLOps: MLflow, Custom model registry, Feature store

LEADERSHIP EXPECTATIONS:
- Technical strategy for 20+ engineer org
- Cross-team architectural decisions
- Growing senior engineers to Staff level
- Influencing without authority across ML/Product/Data
- Incident command for platform-wide issues

BENEFITS:
- Top-of-market equity (pre-IPO)
- Comprehensive health + wellness
- Unlimited PTO + sabbatical after 4 years
- Conference/research budget ($10K/year)
- Home office stipend

INTERVIEW PROCESS:
1. Recruiter screen (30 min)
2. Technical screen - ML systems design (60 min)
3. On-site (5 rounds): ML systems design, distributed systems, coding, behavioral, leadership
4. Executive conversation
5. Team consensus
```

**Key Evaluation Areas:**
1. **ML Infrastructure Depth** - Feature stores, model serving, training pipelines, real-time ML
2. **Distributed Systems at Scale** - 10M+ QPS, partitioning, consistency, latency, availability
3. **Technical Leadership** - Roadmap, cross-org influence, mentoring, hiring, strategy
4. **ML Systems Design** - Feature computation, model serving, A/B testing, model freshness
5. **C++/Python Performance** - Low-latency serving, SIMD, memory management, profiling
6. **Streaming & Storage** - Flink/Kafka, RocksDB/Cassandra, embedding stores, vector DBs
7. **Cross-functional Collaboration** - ML/Product/Data alignment, RFC process, tradeoff analysis
